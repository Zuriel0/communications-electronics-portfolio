# Mi Portafolio Personal 🚀

Este es mi portafolio personal, creado para mostrar mis proyectos, experiencias y las tecnologías que domino, incluyendo programación, sistemas embebidos, electrónica y bases de datos.

## 🛠️ Tecnologías Utilizadas

Este proyecto fue desarrollado utilizando las siguientes tecnologías:

- **[React 19](https://react.dev/)**: Librería principal para construir la interfaz de usuario.
- **[Vite](https://vitejs.dev/)**: Herramienta de compilación súper rápida y empaquetador para desarrollo.
- **[React Icons](https://react-icons.github.io/react-icons/)**: Para íconos limpios y modernos (Io5, Lu, Md).
- **CSS3**: Estilos personalizados adaptables a diferentes dispositivos.

## 📂 Características Principales

- **Sección de Habilidades (Skills):** Tarjetas técnicas que destacan mis competencias en áreas como C/C++, Python, ensamblado, instrumentación, Arduino y manejo de bases de datos.
- **Proyectos:** Un escaparate de mis trabajos destacados con enlaces para explorarlos.
- **Contacto:** Formularios de contacto y enlaces a mis perfiles sociales (LinkedIn, GitHub, etc.) listos para conectar.

## ⚙️ Instalación y Configuración

Si deseas clonar o correr este proyecto localmente, sigue estos pasos:

1. **Clonar el repositorio:**

   ```bash
   git clone <URL_DE_TU_REPOSITORIO>
   cd portafoli_vite_appl
   ```

2. **Instalar dependencias:**
   Usando npm:

   ```bash
   npm install
   ```

3. **Arrancar el servidor de desarrollo:**

   ```bash
   npm run dev
   ```

   El proyecto estará disponible localmente, usualmente en `http://localhost:5173`.

4. **Construir para producción (Build):**
   ```bash
   npm run build
   ```
   Esto generará una carpeta `dist` lista para ser desplegada en cualquier servicio de hosting estático (como Vercel, Netlify o GitHub Pages).

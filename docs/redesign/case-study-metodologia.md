## Overview and challenge

I designed a reusable methodology for customizing digital platforms whose original source code could not be modified. The work is organized around understanding the native interface, recording reusable patterns and preparing technical context for AI-assisted generation. Manual adjustment and validation precede integration. [P; completion C]

The restriction is structural: an external customization must respect existing hierarchies, dependencies and behavior. The earlier process is described as repeated manual analysis, adaptation and checking, dependent on technical memory and difficult to reuse across projects. [P]

## Engineering choices

**Context before generation.** Structure and restrictions are recorded before an AI-assisted proposal is produced. This makes the reasoning inputs explicit rather than relying only on a request to generate code. [P/I]

**Human review before integration.** The sequence retains a manual refinement/validation stage. The AI assists generation; it is not granted independent authority over the platform. [P]

**Reuse documented knowledge.** The account describes reusable patterns as a response to repeated analysis and reliance on memory. It does not establish a particular template library, retrieval system or automated pipeline. [P/I]
